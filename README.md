# Personal Portfolio

A modern and responsive personal portfolio website built to showcase my skills, projects, experience, and achievements as a developer.

The portfolio provides an overview of my technical skills, featured projects, and development journey, along with a way for visitors to get in touch with me. It is designed with a clean, modern interface and responsive layout to provide a smooth experience across desktop, tablet, and mobile devices.

# Features

* Modern and responsive UI
* About Me section
* Skills and technologies section
* Featured projects with project details
* Contact form
* Smooth navigation and animations
* Responsive design for different screen sizes
* Deployed with a custom domain

# Technologies Used

* Next.js
* React
* TypeScript
* Tailwind CSS
* JavaScript
* HTML & CSS
* Git & GitHub

# Purpose

This portfolio was created to showcase my development skills, personal projects, and experience while providing a professional online presence for future opportunities.

# Getting Started

Clone the repository and install the dependencies:

```bash
git clone <your-repository-url>
cd portfolio-modern
npm install
npm run dev
```

The application will be available at `http://localhost:3000`.
